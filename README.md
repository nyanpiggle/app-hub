# app-hub

Phone launcher for public GitHub projects.

1. Repo → Settings → Pages → Deploy from **main** / root.
2. Open https://nyanpiggle.github.io/app-hub/
3. On Android: menu → Add to Home screen.

New **public** repos appear automatically.
Set a repo Homepage URL (or enable Pages) so the tile opens the live app instead of GitHub.

Private repos are invisible to this page (no token in the browser).
